# AsteroidAnchor · 碎石堆小行星锚定机构研究

本仓库围绕**一篇以新锚定机构为核心的论文**组织合作研究。机构形式、具体研究问题和目标期刊尚未确定；先从原始文献和可复现的现象中找出一个值得解决的困难，再选择结构与动作。此前的评价框架、全过程力学和状态识别等构想可以为这篇论文服务，但目前不单独规划理论篇或控制篇。液桥方向由项目负责人另行推进，不列入本合作项目的论文路线。

**状态：论文规划与前期研究。**团队已有文献调研、条件化尺度估算，以及 Zhou 等论文的初步 GPU 离散元复现记录；完整几何、碰撞基准和统计复现仍待核查，源码及原始数据尚未纳入本仓库。尚无新机构的仿真或实验性能结论。论文文字和图表框均是待验证的工作计划。

当前优先研究场景为**几 Pa 级、缺少天然固定支点的松散碎石与细颗粒层 G0**，其中夹杂岩块可能移动；稳定岩石 G1 是后备场景。0.1、1、10、100 N 是探索性的作业力档位，力矩、时长、允许位移和资源要求尚未冻结。微棘临时附着加地下展开锚只是待筛选候选，不能预设其在自由颗粒层中能提供安装反力。这些是前期研究假设，不是论文已经验证的结果。

## 唯一确定的论文

工作题目：**面向碎石堆小行星表面具体锚定困难的新机构设计与验证**。正式题目应在核心困难、机构原理和主要结果明确后确定。

主张必须形成连续的证据链：

```text
现有机构的具体困难及证据
  → 出现条件与力学原因
  → 针对原因改变的结构或动作
  → 模型解释与参数选择
  → 同任务条件下的对照、消融及实验
  → 改善的适用范围、代价和失效边界
```

论文的六个部分及其最低交付如下：

| 部分 | 要回答的问题 | 必须形成的证据 |
|---|---|---|
| 1. 引言与问题定义 | 哪个现有困难仍值得解决，为什么影响任务？ | 原始论文和后续工作的证据表；一句可检验的问题定义 |
| 2. 参考机构与原因分析 | 困难在哪些条件下出现，由什么机制导致？ | 关键结果的复现或独立核验；条件、失败模式与原因的对应关系 |
| 3. 新机构原理与设计 | 哪项结构或动作改变能缓解该原因？ | 结构、动作和载荷路径；与最接近已有方案的具体区别；最小筛选试验 |
| 4. 力学建模与参数设计 | 为什么可能有效，哪些参数控制效果？ | 必要的解析关系或离散元模型、接触参数校准、敏感性与设计取值依据 |
| 5. 对照验证与结果 | 是否改善，改善是否由提出的机制产生？ | 共同任务要求下的参考机构对照、关键结构消融、独立试验、代价与失败统计 |
| 6. 讨论与结论 | 结论适用于哪里，尚不能说明什么？ | 适用条件、模型与实验限制、地面向小行星环境外推的边界 |

评价指标随最终选定的问题确定。安装反力过大时重点看反力、反扭矩和能否完成安装；承载不足时看规定载荷下的承载力、位移与失效；障碍导致部署不可靠时看部署及承载检验的联合通过率。无论主指标是什么，都要同时检查**能否安装**和**安装后能否承载**。质量、功率、能量、时间和可重试性作为相同任务要求下的代价或约束，不能只报告有利的一项性能。

## 先确定一个具体困难

文献调研和复现服务于选题，不必把所有调研结果写入论文。每篇原始文献都要区分：**已经观察到的失败**、**尚未验证的条件**、**作者提出的改进**；继续追踪后续论文，确认改进是否已被实现。不能把未测试的地表写成已证实失效，也不能把已有功能当成新机构原理。

候选困难只有同时满足以下条件才进入机构设计：有可核查的证据；影响明确的锚定任务；后续工作尚未充分解决；存在可针对的结构或动作；团队有能力复现并验证。选题会用下面这句话固定：

> 某类已有机构在某种地表、接触和载荷条件下，因为某个可检验的原因，无法满足某项任务要求；现有证据是……，仍待确认的是……。

参见[文献问题表](研究记录/文献问题表.md)。若复现或后续论文否定某个候选困难，就更换问题，而不为延续投入强行保留它。

每次运行或试验应保存原始数据、工况、参数、失败样本和代码版本，并在[证据登记表](研究记录/证据登记表.md)中登记。标定、方案筛选和最终验证应分开；独立重复单位是完整试验或独立制备的颗粒床等，不能把同一次运行的帧或颗粒当成独立样本。地面装置提供的支撑、围压和反力必须记录，不能直接当作微重力验证。
