# AsteroidAnchor · 碎石堆小行星锚定研究

本仓库维护 AsteroidAnchor 的论文规划与研究证据索引。当前规划四篇相互关联的论文：先建立任务导向的评价基准与全过程理论，再发展机械式多阶段自适应锚定系统，同时独立研究液桥增强锚定的可行性与边界。

**当前全部文稿均处于研究规划阶段。仓库中没有本项目已经完成的仿真、实验结果或已证实结论。**题目、方法和论文数量将随文献核实与实际证据调整。

## 论文路线

| 编号 | 工作题目与核心问题 | 当前定位 |
|---|---|---|
| P0 | **面向碎石堆小行星任务的锚定机构多指标评价与证据化比较框架**：怎样在不同任务需求、数据缺失和证据强弱不一的条件下公平比较现有锚定技术？ | 评价基础；系统综述、指标体系与不确定性排序 |
| P1 | **碎石堆小行星表面从初步接触到稳固锚定的分阶段力学与全过程可行性理论**：什么条件下存在从首次接触通向作业承载的连续可行路径？ | 通用理论；不预设具体机构 |
| P2 | **基于全过程可行性理论的碎石堆小行星多阶段自适应锚定系统设计与验证**：如何用机构、感知和部署策略实现并验证 P1？ | 机械系统主线；状态识别和自适应部署均属于本篇 |
| P3 | **真空微重力环境下液桥诱导风化层增强的锚定可行性与失效边界**：局部毛细黏聚能否转化为系统级锚定能力？ | 独立物理路线；否定结果在边界明确时同样有效 |

研究关系不是固定的投稿顺序：

```text
P0 任务、指标与现有技术证据 ──┐
                              ├─→ P2 机械式多阶段自适应锚定系统
P1 全过程可行性理论 ──────────┘
                 └──────────────→ P3 液桥路线的全过程评价
```

P0 与 P1 可并行推进。P2 应能说明每项设计由 P1 的哪条约束导出，并使用 P0 的任务指标与既有技术比较。P3 可独立开展；它不以最终证明液桥锚定可用为成篇前提。

## 共同研究原则

1. **论文围绕可检验问题组织。**建模、复现、实验、算法和样机都是证据，不自动各算一篇论文。
2. **允许零结果和否定结果。**分阶段方案、具体机构、自适应策略和液桥方案都可以被证据否定；应报告限制机制和适用边界。
3. **以全过程联合成功为主指标。**最大抗拔力、识别准确率和局部材料强度只能解释结果，不能替代从接触到作业承载的完整成功定义。
4. **先检查硬约束，再讨论综合分数。**不满足任务载荷、安装反力、环境或资源上限的方案不能靠其他高分补偿。
5. **性能与证据质量分开。**概念、仿真、固定台架、真空试验、低重力试验和飞行验证不能作为同等级证据。
6. **保证独立性。**材料标定、模型选择、算法调参和最终评价分开；同一次运行的帧、颗粒或采样点不是独立重复。
7. **记录失败与拒判。**不能只统计成功部署样本的承载力，也不能用大量拒判制造虚假的高可靠度。
8. **明确地面外推边界。**只减轻机器人重量并没有降低整个颗粒床的重力与围压。

## 四篇论文的最低成篇门槛

### P0 · 评价框架

需要系统检索与可审计的数据提取规则、任务条件化指标、硬约束、证据分级、不确定性传播和权重敏感性。若现有数据不足以稳定排序，应形成标准化试验需求和“为何不可比较”的定量结论。简单加权表格不足以独立成篇。

### P1 · 全过程理论

需要一个可计算或可判定的路径可行性问题、至少一条超出“最终强度越大越好”的非平凡规律、分阶段相对单阶段的收益/失效条件，以及能够直接转化为 P2 设计要求的约束。若最终只是流程图或串联系统可靠度，应并入 P2 的理论章节。

### P2 · 自适应系统

需要由 P1 明确导出的具体机构、可实现传感、状态可识别性、自适应部署、与固定流程和简化方案的公平对照，以及从首次接触到目标载荷的独立全过程验证。若复杂策略不优于简单规则，应保留简单规则并收缩方法主张。

### P3 · 液桥锚定

需要区分液桥、注入扰动、压实重排和润滑，贯通“液体保持—局部增强—锚具接口—外围风化层”的载荷链，并给出环境、剂量、时间和整体承载边界。仅证明湿颗粒变强或仅测试一种液体不足以成篇。

## 日常工作方式

每项新工作开始前先回答：

1. 它检验哪项主张或竞争解释？
2. 它形成哪张图、表或验证证据？
3. 对照、独立重复单位和判定标准是什么？
4. 如果不做，论文会留下什么关键缺口？
5. 结果不符合预期时，如何修改、合并或停止该路线？

完成运行或实验后，在 [`研究记录/证据登记表.md`](研究记录/证据登记表.md) 登记主张、图表、原始数据、运行/试验编号、参数、代码版本、状态和结论。原始数据、程序和运行日志可另行管理，但正式图表必须能够追溯到稳定版本或归档地址。

## 编译

四篇规划稿都使用标准 LaTeX `article` 类，不锁定目标期刊。在任一论文目录执行：

```sh
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

也可以依次运行 `pdflatex main.tex`、`bibtex main`、再运行两次 `pdflatex main.tex`。当前参考文献开关保持关闭；加入真实正文引用并核实文献库后再启用。编译产物不纳入版本管理。
