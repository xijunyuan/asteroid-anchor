# 文献问题表

用途：从原始论文和后续研究中确认一个仍值得解决、可复现且可验证的锚定困难。每行对应**具体机构配置和试验条件**，不能把一种技术的局部结果概括为整类机构的结论。任何记录都应保留页码、图表或数据出处。

| 字段 | 要记录的内容 |
|---|---|
| 文献与后续工作 | DOI/链接、年份、版本；引用它的后续改进论文 |
| 机构与安装过程 | 结构、动作、反力来源、载荷路径、适用地表和边界 |
| 任务与试验条件 | 重力、真空、颗粒级配、密实度、块石、初始接触、载荷方向、支撑方式 |
| 已观察到的困难 | 失败现象、对应图/表/页码、样本量和量级；未测试条件另列 |
| 原因解释 | 作者的解释、其他竞争解释及各自证据 |
| 作者建议与完成状态 | 建议的改进、原文是否已经实施、后续工作是否已解决 |
| 复现条件 | 所需模型、参数、装置、可观测量与工作量 |
| 选题判断 | 对任务的影响、机构改进空间、验证可行性、仍存的不确定性 |
